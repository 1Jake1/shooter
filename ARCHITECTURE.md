## 🏗️ Модульная архитектура

### Основные принципы:
1. **Разделение ответственности** - каждый модуль отвечает за одну функцию
2. **Инкапсуляция** - внутреннее состояние скрыто, доступ через публичные методы
3. **Слабая связанность** - модули взаимодействуют через четкие интерфейсы
4. **Единая точка входа** - main.js координирует инициализацию

### Поток данных:
```
main.js (инициализация)
  ↓
LoadingManager → загрузка ресурсов
  ↓
SoundSystem, RenderSystem, InputSystem → инициализация систем
  ↓
MapBuilder → построение карты
  ↓
Player + ZombieSystem → спавн сущностей
  ↓
Game Loop (update) → обновление всех систем
```

## 📦 Описание модулей

### Core (Ядро)
- **main.js** - Точка входа, координирует инициализацию и игровой цикл
- **config.js** - Константы и настройки игры (баланс, параметры)
- **state/** - Хранилище состояния (game, player, weapon)

### Systems (Системы)
- **SoundSystem** - Воспроизведение звуков, аудио контекст
- **RenderSystem** - Three.js сцена, камера, рендеринг
- **InputSystem** - Обработка ввода (клавиатура, мышь)
- **PhysicsSystem** - Коллизии, проверка столкновений
- **WeaponSystem** - Стрельба, перезарядка, гранаты
- **ZombieSystem** - ИИ зомби, спавн волн
- **PlayerSyncSystem** - Мультиплеер синхронизация
- **ParticleSystem** - Частицы, эффекты взрывов

### Entities (Сущности)
- **Player** - Игрок, позиция, здоровье
- **Zombie** - Зомби, анимации, поведение
- **Grenade** - Граната, физика, взрыв
- **Target** - Мишень для тренировки

### Maps (Карты)
- **MapBuilder** - Базовый класс для карт
- **Map1/2/3** - Конкретные реализации карт

### UI (Интерфейс)
- **UIManager** - Управление UI элементами
- **Minimap** - Отрисовка миникарты
- **LoadingManager** - Экран загрузки
- **HUD** - Отображение здоровья, патронов

### Utils (Утилиты)
- **Loader** - Загрузка моделей, текстур, звуков
- **Helpers** - Математические функции, хелперы

## 🔄 Игровой цикл

```javascript
// main.js
function gameLoop(deltaTime) {
  InputSystem.update();
  PhysicsSystem.update(deltaTime);
  WeaponSystem.update(deltaTime);
  ZombieSystem.update(deltaTime);
  ParticleSystem.update(deltaTime);
  PlayerSyncSystem.sendUpdate();
  RenderSystem.render();
  requestAnimationFrame(gameLoop);
}
```

## 🎯 Преимущества новой архитектуры

1. **Поддерживаемость** - Легко найти и исправить баги
2. **Масштабируемость** - Простое добавление новых функций
3. **Тестируемость** - Каждый модуль можно тестировать отдельно
4. **Читаемость** - Понятная структура, меньше кода в файле
5. **Переиспользование** - Модули можно использовать в других проектах
