# 📦 Структура проекта Zombie Shooter

## Архитектура

Проект был рефакторизован из одного файла `game-client.js` (3800+ строк) в модульную архитектуру с разделением ответственности.

## 📁 Новая структура

```
/workspace
├── client/                      # Клиентская часть
│   ├── index.html               # HTML страница игры
│   └── js/
│       ├── main.js              # Точка входа, игровой цикл
│       ├── config.js            # Конфигурация и константы
│       ├── state/
│       │   ├── gameState.js     # Состояние игры
│       │   ├── playerState.js   # Состояние игрока
│       │   └── weaponState.js   # Состояние оружия
│       └── systems/
│           ├── SoundSystem.js   # Аудио система
│           ├── InputSystem.js   # Управление (клавиатура, мышь)
│           ├── RenderSystem.js  # Рендеринг (Three.js)
│           └── PhysicsSystem.js # Коллизии, движение
├── server.js                    # Серверная часть (Socket.IO)
├── game-client.js               # Старый монолитный файл (можно удалить)
├── game.html                    # Старый HTML (можно удалить)
└── ARCHITECTURE.md              # Документация архитектуры
```

## 🚀 Как запустить

1. Откройте `/client/index.html` в браузере через локальный сервер
2. Или используйте существующий сервер: `node server.js`
3. Перейдите на `http://localhost:3000/client/index.html`

## 🎯 Модули

### Core
- **main.js** - Координирует все системы, управляет игровым циклом
- **config.js** - Константы игры (баланс оружия, физика, настройки)

### State Management
- **gameState.js** - Глобальное состояние (счет, волна зомби, карта)
- **playerState.js** - Здоровье, позиция, скорость игрока
- **weaponState.js** - Текущее оружие, патроны, перезарядка

### Systems
- **SoundSystem.js** - Загрузка и воспроизведение звуков
- **InputSystem.js** - Обработка ввода клавиатуры и мыши
- **RenderSystem.js** - Three.js сцена, камера, освещение
- **PhysicsSystem.js** - Проверка коллизий, спавн позиции
