# FPS Шутер - Многопользовательская игра

Тактический FPS шутер с системой лобби и поддержкой манекенов (целей).

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер:
```bash
npm start
```

3. Откройте браузер и перейдите по адресу:
```
http://localhost:3000/lobby.html
```

## Возможности

### Система лобби
- Создание лобби с уникальным ID
- Присоединение к существующим лобби
- Выбор команды (для карты "Базы")
- Настройки доступны только хосту:
  - Выбор карты (Арена или Базы)
  - Включение манекенов (цели для стрельбы)

### Карты
1. **🏟️ Арена** - Свободный бой, зеркальная карта
2. **⚔️ Базы** - Командный бой, 2 команды (красные и синие)

### Манекены
При включении опции "Включить манекены" на карте появляются статичные цели для тренировки стрельбы.

### Управление
- **WASD** - Движение
- **Мышь** - Обзор
- **ЛКМ** - Стрельба / Бросок гранаты
- **ПКМ** - Прицел (SSG-08)
- **R** - Перезарядка
- **1-5** - Смена оружия
- **SHIFT** - Бег
- **ПРОБЕЛ** - Прыжок

### Оружие
1. **Пистолет** - Стандартное оружие, средний урон
2. **Автомат** - Автоматический огонь, высокая скорострельность
3. **SSG-08** - Снайперская винтовка с прицелом, высокий урон
4. **Осколочная граната** - Взрывной урон по области
5. **Дымовая граната** - Создает дымовую завесу

## Технологии
- **Three.js** - 3D графика
- **Socket.IO** - Многопользовательская синхронизация
- **Express** - Веб-сервер
- **Node.js** - Серверная часть
